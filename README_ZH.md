# 🏰 洛克沙盘

> 洛克王国：世界 6v6 单打 PVP 对战辅助桌面应用 —— 回合推演、AI 教练、伤害反推、实战修正。

[English](./README.md) | 简体中文

---

## 🎯 项目简介

洛克沙盘是一款桌面辅助工具，在你进行 PVP 对战时作为旁观参谋使用。

- 🧩 游戏画面告诉你血量百分比和伤害数字，**洛克沙盘告诉你这些数字背后的含义**
- 🎯 推测对手的性格与个体值
- 📊 预判接下来几个回合的胜负走向
- 🤖 AI 教练给出回合操作建议
- 🔧 系统推演与实际不符时可即时修正

所有建议基于 **PVP 导论**：从 Check/Counter 对位关系、冗余战术、非冗余战术角度分析，而非简单比较伤害数字。

---

## 🤖 AI 多轮教练

- 🧠 **真对话记忆** — AI 记住回合 2 给出的建议，在回合 3 能接续上文推理
- ⚡ **开局预加载** — 第一只敌方出场即注入全队上下文，后续每回合仅发送轻量快照
- ↩️ **撤销同步** — 回退回合时 AI 对话历史同步裁剪
- 💾 **会话持久化** — 数据存储在浏览器本地，刷新或重启不丢失
- 💰 **实际成本** — 约每回合 0.001 元，一局 30 回合约一分钱

---

## 🎯 核对条

每回合执行后底部弹出确认条，1.5 秒进度条走完后自动确认。

- ✅ **普通回合**自动通过，无需操作
- 🔴 **关键事件**（击倒、首领化、印记层数变化、冰冻）强制手动确认
- 📝 按 `E` 键展开修正面板，可调整敌方血量百分比、我方血量、实际伤害、双方能量
- ⏳ AI 在核对条存续期间不发送，修正完成后才触发

---

## 🧠 伤害反推引擎

输入游戏画面中实际看到的伤害数字，引擎反向求解伤害公式，推测敌方的攻击数值区间。

多次观测后区间收窄。修正 3 到 5 次即可锁定敌方性格名，并将攻击数值精确到正负 10 以内。后续伤害预测使用推测区间，而非默认热门配置。

敌方面板以紫色徽章显示推测结果：

> `物攻≈195·偏执 / 魔攻≈210·专注（5次）`

---

## ⏪ 回合时间线

每个回合的状态（执行前、执行后、双方操作）均被记录，在底部以横向时间线展示。

- 🔍 点击任一历史回合可进行事后修正
- 📌 **「仅此一回合」**：只覆盖该回合的显示数据，不影响后续
- 🔄 **「重算到当前」**：用修正后的状态重新推演后续所有回合
- 🤖 AI 同步收到修正通知

## 📥 公式导入

支持粘贴官方分享格式（B 站配队帖常见形式），一键导入全部 6 只精灵：

```
### 平衡帅魔偶
# 魔法：进化之力
#
# 海豹船长：武系血脉、{斩断、听桥、力量增效、水刃}
# 帅帅魔偶：恶系血脉、{借用、借用、借用、贪婪}
...
```

导入时自动匹配精灵名、血脉、技能、魔法道具。性格与个体值沿进化链及首领形态反查推荐配置。

> ⚠️ 导入的性格与个体值为推荐配置，如与实际不符请手动调整。

## 🔍 拼音首字母搜索

全部搜索框均支持输入汉字拼音首字母快速定位：

- `t` → 听桥、隐藏条款（任意汉字首字母含 t 的技能）
- `tq` → 听桥（前两字拼音首字母为 t 加 q）
- `dm` → 迪莫
- `sg` → 筛管奔流

覆盖范围：技能搜索、精灵搜索、图鉴搜索、配队搜索、借用弹窗、敌方系别展开。

## ⚙️ 特性系统

已覆盖约 95% 的精灵特性，包含五大处理器与两个补充系统：

- 🚪 **入场特性** — 约 30 种效果
- 🚶 **离场特性** — 清除或转移效果
- 🔄 **回合结束特性** — 合拍、奉献、自动脱离等
- 🛡️ **应对特性** — 应对成功触发反击增益
- ⚔️ **攻击时特性** — 约 25 种模式
- 🏐 **咕噜球** — 14 种球效果
- 🌸 **兽花蕾血脉** — 18 种系别效果

换人时仅保留蓄电池入场次数和魔力值，其余清除并在重新入场时重算。

## 🚀 快速开始

### 📋 环境要求

- Node.js 18 及以上
- Rust（构建桌面应用需要）
- Windows 10 或 11

### 🔧 安装与运行

```bash
git clone https://github.com/HZ-KMNO/roco-sandbox.git
cd roco-sandbox
npm install
npm run tauri dev     # 完整桌面应用（推荐）
# 或
npm run dev           # 仅前端，浏览器打开 http://localhost:1420
```

### 📦 构建安装包

```bash
npm run tauri build
```

> 💡 如遇 Windows 提示「已保护你的电脑」或「无法识别发布者」，请点击「更多信息」→「仍要运行」。本软件为安全的开源项目，未购买代码签名证书。

### 🔑 配置 AI

无需 AI Key 也能使用，系统会自动降级为规则引擎建议。启用 AI 的步骤：

1. 在 DeepSeek 开放平台获取 Key（参阅 API 教程）
2. 应用内进入设置页，粘贴 Key
3. 添加第一只敌方精灵后 AI 自动开始工作

## 📐 单回合数据流

```
用户选择操作 → Space 执行
  → resolveTurn() 结算 → 新状态
    → TurnRecord 写入时间线
      → 核对条弹出（1.5 秒）
        ├─ 关键事件 → 红色，必须确认
        ├─ 按 E → 展开修正面板
        │   └─ 应用 → 写入 BattleState 与观测记录
        └─ 自动或手动确认
          → getTurnAdvice() 发送多轮对话
            → AI 回复 + 本地持久化

撤销 → 回退状态 + 裁剪 AI 历史 + 提示条
事后修正 → 时间线 → 仅此一回合或重算到当前
```
