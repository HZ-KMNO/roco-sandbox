# 洛克王国：世界 — 对战速查手册

本手册提供紧凑的决策框架，用于快速分析对手并给出操作建议。

---

## 一、分析模型

每一回合的决策，按五个层次递进分析：

1. **事实层** — 场上精灵、血量（HP）、能量、已暴露技能、增益减益、印记、首领化状态、共鸣魔法、天气场地
2. **顺序层** — 换人/首领化 ＞ 应对成功 ＞ 技能先手修正/迅捷 ＞ 速度
3. **资源层** — 能量预算、冷却、场地效果、剩余后排、关键克制位
4. **压力层** — 双方留场 / 换人 / 防御 / 状态各自会发生什么
5. **计划层** — 当即操作、备选方案、下回合衔接

---

## 二、核心术语

| 术语 | 含义 |
|------|------|
| **先手压制（Check）** | 双方同时入场时，自己能稳定击倒对方 |
| **后手压制（Counter）** | 对方已在场先出手一回合，自己后换入仍能击倒 |
| **场上压力** | 当前场上精灵对对手产生的换人驱动力 |
| **场下压力** | 后排精灵的存在对对手决策造成的影响 |
| **集中施压** | 多只攻击手针对同一防守目标持续消耗，直至过劳 |
| **突破战术** | 不以共享目标为前提，而是独立创造入场机会或突破口 |
| **炮台** | 一旦安全上场就能产生极高收益的精灵/配置 |
| **防守过劳** | 防守端反复应对后血量、能量、冷却全面下滑，不再能承接 |

---

## 三、队伍建议

1. 收集用户的六只精灵和主要目标
2. 判断队伍主线：
   - 集中施压（多线打击同一目标）
   - 炮台上场（反复送核心入场）
   - 印记/场地战术（改造环境获优势）
   - 联防消耗（依靠换人轮转消耗对手资源）
   - 捕获/地雷（打破对方防守结构）
3. 找出弱点：
   - 核心打手缺少安全入场方式
   - 对常见热门精灵没有有效克制手段
   - 高费技能过多，能量周转困难
   - 无法处理或利用印记
   - 主线打法没有备选方案
4. 给出 1-3 条改进建议，附理由
5. 涉及具体技能数据时，使用本地工具查询

---

## 四、回合建议

先确定：
- 当前场上精灵、血量、能量
- 已暴露的技能和状态
- 后排存活情况
- 关键资源是否仍可用

然后逐一回答：
1. 如果我留场，会发生什么？
2. 如果对方留场，会发生什么？
3. 对方最可能换谁？
4. 如果我猜错，最坏的结果是什么？
5. 如果我猜对，收益是什么？

输出格式：
- **首选** — 收益与风险的最佳平衡
- **备选** — 更稳妥或更高风险的替代方案
- **不建议** — 因能量、顺序、克制等原因不可行的选项

## 五、复盘分析

失误分四类：

| 类型 | 说明 |
|------|------|
| **构筑问题** | 队伍本身缺少可行的应对手段 |
| **操作问题** | 应对手段存在但使用不当 |
| **信息问题** | 漏看或忽略了对局中已暴露的信息 |
| **合理猜拳** | 选择本身是合理的，结果不理想只是概率问题 |

不要把所有猜错都归咎于"失误"。只有当证据薄弱、失败代价高、收益低时，这个决策才是真正糟糕的。

## 六、常见问题模式

**"我打不动某只精灵"** → 检查是否可以通过反复施压使其过劳。推荐第二只具有重叠压力的攻击手、压低能量、印记/场地路线或隐藏地雷配置。

**"该不该换人？"** → 换人的前提是：留场会直接损失关键精灵且得不到足够补偿、换入精灵能安全上场并立即行动、换人能保住必要克制位。不换的前提是：当前精灵仍能制造压力、换人给对方白送回合、换入精灵只是"check"而非"counter"。

**"这只算不算 Counter？"** → 自问三点：能否在对方已站场时安全换入？能否扛住对方的常用攻击/状态/防御线路？换入后能否仍造成有效压制？不满足则只算"Check"或"条件Counter"。
