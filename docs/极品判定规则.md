# 精灵极品判定规则

来源：B站UP主火播君《北极熊教你如何判断洛克王国世界极品精灵》

## 天分等级

| 天分 | 增幅属性数 | 条件 |
|------|-----------|------|
| 了不起 | 3条 | 增加的3条中至少1条命中性格影响的属性 |
| 相当好 | 3条 | 增加的3条均未命中性格影响的属性 |
| 其他 | <3条 | 普通品质 |

判断逻辑：性格有+10%属性（如开朗→+速度），如果天分增加的3条属性中包含速度，则显示"了不起"；否则即使3条也是"相当好"。

## 性格与种族值匹配

- 物理攻击型（物攻>魔攻）：推荐加物攻/速度，减魔攻
- 魔法攻击型（魔攻>物攻）：推荐加魔攻/速度，减物攻
- 防御/辅助型：推荐加防御/体力，减攻击项

## 应用中的实现

- 性格选择器已支持25种性格
- 天赋选择器支持选3项（个体值+10）
- 天分等级：根据选中的天赋是否包含性格加成属性，自动判定"了不起"或"相当好"
