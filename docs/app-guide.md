## 快速开始

**第一步：安装应用**

下载 `RocoSandbox_Setup.exe` 安装包，双击运行安装。安装完成后桌面出现「洛克沙盘」图标。

**第二步：配置 AI（可选）**

1. 打开应用 → 进入「设置」Tab
2. 在 🤖 AI 区域粘贴 DeepSeek API Key
3. 没有 Key 也能用 — 系统自动降级为规则引擎建议

**第三步：开始对战**

1. 在「对战」Tab 的我方队伍面板添加你的 6 只精灵
2. 对局开始后，在敌方面板添加对手的首发精灵
3. AI 自动预加载 → 开始给出建议

## 对战 Tab

对战 Tab 是核心功能区，分为四大面板。

### 我方队伍面板

**添加精灵**

1. 点击搜索框，输入精灵名或拼音首字母（如 `dm` → 迪莫）
2. 点击精灵加入队伍（最多 6 只）
3. 双击精灵卡设为 ⭐ 首发

**配置精灵**

每只精灵卡片可配置：

| 项目 | 操作 |
|------|------|
| 性格 | 下拉选择（如固执、胆小） |
| 个体值 | 勾选 3 项加成属性（生命/物攻/魔攻/物防/魔防/速度） |
| 技能 | 搜索并选择 4 个技能（支持拼音首字母） |
| 血脉 | 选择系别（武系/水系/翼系等） |
| 咕噜球 | 选择球的类型（普通球/国王球/美妙球等） |
| 兽花蕾 | 选择稀兽花宝血脉 |
| 技能石 | 开启后可选全技能库任意技能 |

**快捷添加随机技能**

借用/复写/取念技能旁有 `+` 快捷按钮。盲从特性精灵（如帅帅魔偶）可重复添加多个。

**公式导入**

点击「公式导入」按钮，粘贴官方配队分享文本，一键导入全部 6 只精灵（含技能、血脉、性格、魔法道具）。

**队伍管理**

- 顶部下拉切换多套队伍
- 「导出」按钮复制队伍到剪贴板（可分享给他人）
- 队伍自动保存到本地

**天分等级**

系统自动判断：
- 「了不起」：3 项个体值中有 1 项包含性格加成的属性
- 「相当好」：3 项个体值均不含性格加成属性

### 敌方队伍面板

**添加精灵**

对局开始后，根据游戏画面把对手出场的精灵逐一添加：
1. 搜索精灵名或拼音首字母
2. 点击加入敌方列表
3. 点击选中当前对战精灵（高亮显示）

**快捷导入**

- 公式导入：粘贴对手的配队文本

**热门配置显示**

敌方精灵下方自动展示 B 站「十有九成」推荐的性格和个体值参考。

### 对局建议面板

位于页面左下方，提供两种模式（设置中切换）：

**AI 建议模式**

- 添加第一只敌方精灵后自动触发 AI 预加载
- 每回合执行后自动请求 AI 分析
- 可手动点击「AI 分析」按钮重新请求
- AI 具有多轮记忆，能参考之前回合的建议
- AI 历史折叠显示在下方

**规则引擎模式**

- 基于 Check/Counter 对位关系
- 实时计算最优操作
- 不需要网络连接

**输出格式**

```
建议：使用 XXX 技能
理由：当前对位我方 Check 对方，先手可 2 回合击倒...
```

### 对局分析面板

三栏布局：**技能 | 魔法 | 换人**

**技能栏**

- 显示我方和敌方的 4 个技能槽
- 点击技能选择本回合操作
- 显示费用、威力、系别、分类（物攻/魔攻/防御/状态）
- 顶部搜索框支持拼音过滤
- 随机技能（借用/取念/复写）有 ⊕ 按钮选择本回合随机到的技能
- 敌方借用/取念/复写有 ▼ 展开技能列表（支持系别筛选 + 全局搜索）

**魔法栏**

- 进化之力：首领血脉精灵可使用，每场 1 次
- 愿力强化：2 费 100 威攻击（应对状态时 250 威），每场 2 次，3 回合 CD

**换人栏**

- 显示后排精灵列表
- 点击即选择换人操作

**执行回合**

1. 选择我方操作（技能/魔法/换人）
2. 选择敌方操作（根据游戏画面）
3. 按 **Space** 键或点击「执行回合」按钮
4. 系统结算回合（伤害、状态、特性触发等）
5. 弹出核对条 → 确认或修正

**HP/能量调整**

精灵面板下方有快捷按钮：
- HP：-100 / -50 / 半血 / 满血 / +50
- 能量：-1 / +3

**特性标签**

精灵卡上方显示当前生效的特性效果：
- ⟳ 绿色标签：跨场累积（换人保留，如蓄电池、魔力值）
- 琥珀色标签：当前场次（换人清除并重算）
- 悬停查看详细说明和是否永久

**撤销**

点击「↩ 撤销」按钮回退上一回合（同时撤销 AI 对话）。

## 复盘 Tab

**功能**

对局结束后进行回顾分析。

**操作步骤**

1. 从游戏中复制对战记录
2. 粘贴到复盘页的输入框
3. 系统自动解析为结构化回合展示
4. 点击「AI 复盘分析」获取 AI 对每回合的分析

**数据**

- 最多保存 50 条复盘记录
- 显示统计：总场次、平均回合数、总回合数

## 配队 Tab

**浏览热门配队**

- 自动加载线上热门配队数据
- 支持按精灵名/拼音搜索
- 支持按属性筛选（草/火/水/光/地/冰/电/毒/虫...）
- 每支队伍显示属性圆点预览和 ♥ 喜欢数

**导入配队**

点击展开队伍详情，有两个按钮：
- 「导入我方」：整支队伍导入到对战 Tab 我方面板
- 「导入敌方」：整支队伍导入到对战 Tab 敌方面板

**我的模板**

- 点击「保存」将当前配队存为模板
- 模板可删除
- 点击「导入」按钮粘贴文本导入

**导入文本格式**

支持两种格式：

格式一（官方分享）：
```
### 队伍名称
# 魔法：进化之力
#
# 海豹船长：武系血脉、{斩断、听桥、力量增效、水刃}
# 帅帅魔偶：恶系血脉、{借用、借用、借用、贪婪}
...
```

格式二（简易）：
```
迪莫#1//固执//生命物攻速度光球/魔法增效/棘突/火焰箭
恶魔狼#131//开朗//物攻速度防御暗袭/恶之波动/防御/聚能
```

## 进阶功能

### 公式导入

**适用场景**：从 B 站/社区看到别人分享的配队，想快速导入试用。

**操作步骤**

1. 复制对方分享的配队文本（含 `### 队伍名 / # 精灵名：血脉、{技能}` 格式）
2. 对战 Tab → 我方面板 → 点击「公式导入」
3. 在弹窗中粘贴文本
4. 点击「解析代码」→ 显示识别到的精灵列表
5. 点击「确认导入」→ 自动创建新队伍，6 只精灵全配好

**自动填充规则**

| 字段 | 填充逻辑 |
|------|----------|
| 精灵 | 按名称精确/模糊匹配 |
| 血脉 | 从 `武系血脉` 提取系别 |
| 技能 | 从 `{技1、技2、技3、技4}` 提取并匹配技能库 |
| 性格 | 优先 B 站推荐；找不到沿进化链回溯；都没有用「平衡」 |
| 个体值 | 同上（进化链 + 首领反查） |
| 魔法 | 从 `# 魔法：进化之力` 提取 |

### 拼音首字母搜索

**所有搜索框均支持**（6 处）。

**用法**

| 输入 | 匹配逻辑 | 示例 |
|------|----------|------|
| `t` | 任何字的首字母含 t | 听桥、隐藏条款、天雷 |
| `tq` | 前两字首字母 t + q | 听桥 |
| `sgbl` | 四字首字母完全匹配 | 筛管奔流 |
| `dm` | 前两字首字母 | 迪莫 |
| 中文 | 直接包含匹配 | 输入「光」匹配「光合作用」 |

### 核对条与数据修正

**为什么需要**：系统使用默认性格/个体值计算，实际游戏中敌方的配置可能不同，导致推演结果和真实情况有偏差。

**核对条流程**

1. 每回合执行后，底部弹出核对条（1.5 秒进度条）
2. 数值正确 → 无需操作，自动确认
3. 数值不对 → 按 **E** 展开修正面板

**修正面板字段**

| 字段 | 说明 |
|------|------|
| 敌方 HP | 输入游戏中看到的百分比（如 42） |
| 我方 HP | 输入游戏中看到的数值（如 3120） |
| 实际伤害 | 输入敌方对我方造成的真实伤害（如 280） |
| 能量（高级） | 展开后可修改双方能量 |

**关键事件**

以下情况核对条变红，必须手动按 Enter 确认：
- 任一精灵被击倒（KO）
- 进化之力发动
- 印记层数变化（蓄电 1→2、星陨累加等）
- 冰冻层数增加
- 换人发生

### 回合时间线与事后修正

**位置**：对局分析面板底部（默认折叠，显示 ▸ 时间线 (N 回合)）。

**查看**

点击 ▸ 展开 → 显示 R1、R2、R3... 横向按钮条。每个按钮显示：
- 回合号
- 双方操作（如「听桥/防御」）
- 双方剩余 HP%

**事后修正**

场景：你在 R5 时发现 R3 的数据其实是错的。

1. 展开时间线 → 点击 R3
2. 选择模式：
   - 「只改这条」：仅覆盖 R3 的显示数据，不影响后续
   - 「重算到当前」：用修正后的 R3 状态，重新跑 R4、R5 的回合结算
3. 填写修正数值 → 点击「应用」
4. AI 收到通知：`[事后修正] R3 数据已修正：敌方实际HP 60%`

### 伤害反推引擎

**原理**

游戏中能看到伤害数字，但看不到敌方的攻击/性格/个体值。反推引擎利用伤害公式逆向计算：

```
已知: 伤害、我方防御、技能威力、属性克制、同系加成
求解: 敌方攻击数值
```

**使用流程**

1. 回合结束 → 核对条弹出 → 按 E
2. 在「实际伤害」字段输入游戏中看到的数字
3. 应用 → 系统记录这次观测
4. 多次观测后（3-5 次），敌方面板上出现紫色徽章

**徽章格式**

```
物攻≈195·偏执 / 魔攻≈210·专注（5次）
```

含义：
- `物攻≈195`：推测的物攻数值
- `·偏执`：最匹配的性格名
- `（5次）`：基于 5 次观测
- 置信度越高（观测越多），区间越窄，性格名后面的 `?` 会消失

### AI 多轮教练

**与普通 AI 的区别**

| 普通 AI | 洛克沙盘 AI |
|---------|------------|
| 每回合独立，不记之前给的建议 | 记住全部历史对话，能接上文 |
| 固定 system prompt | 预注入全队数据 + 对位矩阵 + 战术分析 |
| 无法修正 | 撤销时同步裁剪 AI 历史 |
| 不知道自己错了 | 收到事后修正通知，调整后续建议 |

**AI 收到的上下文**

每回合 AI 看到：
- 全队信息（精灵/特性/技能/种族值）
- 对位矩阵（Check/Counter 关系预计算）
- 当前回合状态（HP/能量/状态/印记/天气）
- 近 3 回合历史操作
- 规则引擎的初步建议
- 之前所有回合的 user→AI 对话

**撤销与 AI**

撤销回合时：
1. BattleState 回退
2. AI 对话历史自动裁掉对应回合
3. 显示灰色横线：「↩ 已撤销 R3 之后的 2 条 AI 对话」
4. 下次 AI 调用只看到裁剪后的干净上下文

## 常见问题

**Q：没有 DeepSeek API Key 能用吗？**

可以。系统自动使用规则引擎提供建议，不需要网络。AI 模式需要 Key。

**Q：AI 建议需要花多少钱？**

约 ¥0.001/回合。一局 30 回合约一分钱。DeepSeek 注册有免费额度。

**Q：为什么系统预测和实际伤害不一样？**

因为系统默认使用 B 站推荐的性格和个体值。对手实际配置不同 → 伤害不同。用核对条的修正功能输入实际伤害，反推引擎会逐渐锁定对方真实配置。

**Q：检查更新按钮没反应？**

检查更新需要在 Tauri 桌面客户端中运行。纯浏览器模式（npm run dev）无法调用 Rust 后端。

**Q：首领化怎么操作？**

首领血脉精灵在魔法栏有「进化之力」按钮，点击即可首领化。每场只能用 1 次，不消耗回合。

**Q：借用/取念/复写随机到的技能怎么选？**

点击技能旁的紫色 ⊕ 按钮 → 弹出技能选择窗口 → 搜索并选择本回合随机到的技能。回合结束后自动恢复为原状。

**Q：数据从哪来？**
